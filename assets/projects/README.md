# Скриншоты проектов

Добавляйте сюда изображения для карточек проектов, например:

- `project-1.png`
- `project-2.jpg`

Лучше использовать вертикальные изображения с соотношением сторон около 4:5 или 9:16, минимум 1200 пикселей по ширине. После добавления файла замените соответствующий placeholder в `../../index.html` на закомментированный тег `<img>` под ним и укажите имя вашего файла.
